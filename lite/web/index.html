communico-lite

This chat room is a version-controlled database running entirely in YOUR browser (DoltLite WASM — SQLite with Dolt-style commits, branches and merges). Every message is a commit; the event id is the commit hash. No server, no account: "sign in" just picks the name stamped on your commits.

This room is session-scoped: it lives only in this tab's memory and disappears on reload (no persistent storage available in this browser).
