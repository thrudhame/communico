communico-lite

This chat room is a Matrix event DAG replicated across browser tabs — each tab keeps its own version-controlled DoltLite database. Event ids are content hashes (identical on every replica); each replica ingests into its own store, one commit per event; the database itself certifies convergence via history-independent table hashes. No server anywhere.

This room is session-scoped: it lives only in this tab's memory and disappears on reload (no persistent storage available in this browser).
